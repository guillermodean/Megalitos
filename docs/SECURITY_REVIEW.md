# Security review (pre-publication) - Megalitos Navarra app

Date: 2026-11-11. Scope: `app/` (Express 5 + handlebars + mysql2 + MariaDB 11.4, Docker). Legacy `../Megalitos/` out of scope.
Method: code review plus live testing against the dev stack (http://localhost:8096) and a throwaway container (`megalitos-sec-tmp-app`, removed). Test suite: `test/run.sh` 37 pass / 0 fail / 1 skipped.

Overall: no Critical or High findings. The code is in good shape (all SQL parameterised, escaping by default, strict CSP with no inline code, strict filename regexes). Open items are mostly deployment/network decisions.

## Tests performed (all against dev stack, results as expected)

- XSS/injection: `q=<script>alert(1)</script>`, `"'><img onerror>`, `{{7*7}}`, `a' OR 1=1--`, `+-*()<>~"@`, `%_\` all HTML-escaped (`&lt;`, `&#x27;`) or inert; no `{{{` in views except layout `{{{body}}}`; `nl2p` escapes first; `data-name`/`data-lat` attributes are escaped by `{{ }}`. `map.js` popups use `textContent`/`createElement` (no `innerHTML`); `site.js` has no `innerHTML`. No inline `style=`/`on*=`/inline `<script>` in views.
- Path traversal on `/anexos` and `/anexos/thumbs`: `..%2f`, `%252e%252e%252f`, `..%5c`, `%00`, `.jpg%00`, trailing `%0a`, `%E0%A4%A`, `/anexos/` -> all 404 (strict regex plus `path.basename`). Valid file: 200, `immutable`, `nosniff`. Range requests are disabled (`acceptRanges:false`; returns full 200).
- File disclosure: `/.env`, `/.git/config`, `/package.json`, `/src/server.js`, `/js/map.js.map`, `/js/` -> 404 (`dotfiles:'ignore'`, `index:false`).
- Redirects: legacy ones are hard-coded to relative paths; `/table/vista/1%0d%0aX:y` -> `/megalitos`; `//evil.com` -> 404; spoofed `Host` header is not reflected.
- Methods: POST/TRACE/OPTIONS -> 405 with `Allow: GET, HEAD`; no CORS headers on `/api/*` (`CORP: same-origin`).
- Errors: 404/405/429 pages are generic, `Cache-Control: no-store`, no stack traces; the error handler logs stack server-side only and renders `message`, never `err.message`. DB-down: `/healthz` -> 503 `db unavailable`; page routes reach the error handler -> generic 500 (by code reading).
- Headers (live): CSP (`default-src 'self'`, no unsafe-inline, `frame-ancestors 'none'`, `object-src 'none'`), `X-Content-Type-Options`, `Referrer-Policy: strict-origin-when-cross-origin`, COOP/CORP same-origin, HSTS `max-age=31536000; includeSubDomains` (harmless on HTTP, fine behind Cloudflare; remove `includeSubDomains` only if sibling subdomains of the host would be plain HTTP - they are subdomains of `megalitosnavarra.guillermodean.com`, so none). Cache: HTML `public, max-age=60`, errors `no-store`, `/vendor` `/fonts` `/anexos` immutable 1y, other static 1h. Note: `crossOriginEmbedderPolicy` is off on purpose (tiles).

## Deploy checklist (homelab)

1. Pull latest, `docker compose up -d --build` so S-01/S-03/S-04 take effect. Check `docker exec megalitos env | grep -c ROOT` prints 0.
2. Decide S-02: change `ports` to `"127.0.0.1:8050:8000"` if cloudflared runs on the same host (not in a container on another bridge); otherwise restrict 8050 to the cloudflared IP with a firewall. Note Docker-published ports bypass `ufw` INPUT rules: use the `DOCKER-USER` chain or ufw-docker.
3. `.env`: 600 permissions, strong unique root and app passwords (`openssl rand -base64 32`; avoid `'` and `\` is handled but keep it simple), not in the repo.
4. Backups: `data/mysql` (stop DB or use `mariadb-dump` from the container to a file; the seed can rebuild the DB from `db/init`, so the DB is reproducible), plus `data/anexos` and `data/thumbs` (source images 272 MB). Keep one off-host copy.
5. Cloudflare: Cache rule for `/anexos/*`, `/vendor/*`, `/fonts/*`, `/css/*`, `/js/*` (Cache Everything, respect origin headers); WAF rate limiting rule (e.g. 60 req/min per IP on `/megalitos*` and `/api/*`); Bot Fight Mode on; optionally block non-GET at the edge; "Always use HTTPS". Keep Cloudflare Access off (public).
6. Logs: rotation is now configured (10 MB x 3). Request log has no query strings or IPs. Check `docker logs megalitos --since 1h` after launch.
7. Monitoring: `/healthz` returns 200/503; point Uptime Kuma at the public hostname.
8. Updates: rebuild monthly with `--pull`; run `npm audit` in a `node:22-alpine` container; pin image tags/digests (S-06).
9. Privacy notice: mention OSM/OpenTopoMap/IGN tile requests from the visitor's browser (S-08).
